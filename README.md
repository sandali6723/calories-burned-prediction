🔥 Calories Burn Prediction System

Machine Learning Model & Web Application

This repository contains an end-to-end machine learning–based calorie burn prediction system, including model development, evaluation, and deployment through a web application.

The project demonstrates the complete workflow from data analysis and model selection to real-world usage via an application interface.

📌 Project Overview

The goal of this project is to predict the number of calories burned during a workout based on user physical characteristics and workout parameters using machine learning techniques.

The system is divided into two dedicated branches to maintain clarity and modularity.

🌿 Branch Structure
🔹 ML model Branch

Focuses on machine learning development.

Includes:

Dataset and preprocessing

Feature engineering

Training and evaluation of multiple regression models

Model performance comparison

Final model selection

Research paper and documentation

👉 This branch produces the trained ML model used by the application.

🔹 app Branch

Focuses on application deployment.

Includes:

Backend server

Trained ML model integration

User interface

Real-time calorie prediction output

👉 This branch consumes the trained model generated in the ML model branch.
